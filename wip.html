Ticket text: On /plannings/company, add an additional filter that allows filtering by the user's own custom lists (see /plannings/custom_lists).

Decisions

  • Design Option 1B chosen from the design canvas tmp/design_canvas_ticket7.html (options: 1A single dropdown, 1B multi-select with tag pills, 1C quick-access pills).
  • Multi-select using the existing Selectize wiring (select[multiple].searchable in app/assets/javascripts/application.js.coffee), placed next to the date filter. No JS changes.
  • Several selected lists are combined: the table shows every member of any selected list (a union of their item_ids).
  • Only the logged-in user's own lists with item_type = Employee are offered and honoured (current_user.custom_lists).
  • The selection is remembered in the session as session[:planning_custom_list_ids], the same way the date period is kept in session[:planning_period].
